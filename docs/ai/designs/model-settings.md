# 모델 기준 및 추후 마감재 등록

> 후속 구현: 제품 0.2.0에서 [84A 부분 골조 3D 초안](84a-structural-viewer.md)을 별도 화면에 추가했다. 아래 구현 당시의 "3D 범위 밖" 기록은 0.1.0 기준이며, 마감재를 3D에 적용하는 기능은 여전히 후속 작업이다.

- 날짜: 2026-11-18
- 사용자 요청: 201동 2층 SL을 동 단면도 GL +3,550mm로 적용. 마감 자재는 나중에 추가 가능하게 구현.
- 변경 전: 범용 관리자 샘플 화면과 도면 검토 문서만 있음.
- 변경 후: 인증된 `/model-settings` 화면에서 201동 2층·84A 확장형 기준 확인, 마감재 등록/수정, 부위별 마감층 연결, 사용자별 브라우저 저장과 JSON 백업/복원.
- 구조: `routes → features/model-settings → entities/building-model → shared`. 모델의 높이 기준과 자재 목록/마감층은 분리. 자재 선택/두께 수정이 골조 기준 표고를 변경하지 않음.
- 미정 값: 재료·두께는 null 허용, 임의의 일반값으로 채우지 않음. 층별 정렬은 골조에서 실내 표면 방향의 재료 구성 순서이며 현장 확정 시공 순서가 아님.
- 이번 범위 밖: 자동 PDF/CAD 인식, 실제 3D 형상, 여러 현장 관리, 서버 공동 저장, 이미지/제품 파일 첨부. 일반적인 모델링 전체가 완료됐다고 표시하지 않음.
- 저장: 브라우저/로그인 사용자별 로컬 저장. 같은 기기의 다른 브라우저나 다른 사용자에게 공유되지 않음. JSON 백업·복원 지원. 복원은 런타임 검증 및 확인 후 저장하며 실패 시 기존 데이터를 유지. 손상 데이터는 자동 덮어쓰지 않음.
- 검증: 명시한 표고 고정, 미정 자재·두께 허용, 부위-자재 참조 무결성, 백업 검증/복원, 저장 실패·손상 데이터 처리. 5개 게이트와 브라우저 등록/수정/새로고침/미정/백업·복원/모바일 확인.
- 롤백: 새 route/nav 연결을 제거하면 기존 샘플에 영향 없이 화면 분리 가능. 기존 사용자 변경은 유지.

## 구조도 확인

추가 PDF 3개 각 1페이지를 렌더링하고 텍스트와 대조했다. 원본은 수정하지 않았다.

- `단위세대 구조평면도.pdf`: 84A 세대 AW1~3, AW11~16, SW12, SW20, B2/B3/B3A 등의 부호. MWXX는 "동구조평면도참조"로 남아 있음.
- `벽체일람표-1.pdf`: AW1 2F 250mm, AW2 1F~2F 200mm 등 부호/층별 두께 확인. SW12/SW20은 이 일람표에 없으므로 부호가 비슷한 다른 벽체에 대응시키지 않음.
- `슬라브일람표.pdf`: EV홀 150mm, 일반 상세 거실 210mm 및 화장실 TYPE A/B 155/180mm 등 서로 다른 조건 존재. 해당 세대의 적용 slab 부호와 단차 타입을 동 구조도에서 대조해야 함.
- 추가 필요: **201동 2층 동 구조평면도(부재·슬래브 부호 포함), SW12/SW20 일람 및 B2/B3/B3A 보 일람**. 골조 검토 모델을 완성할 때 필요하며 마감재 관리 화면 구현의 선행 조건은 아님.
- 높이 불일치는 사용자 결정으로 해결: 2층 SL GL +3,550, 3층 SL GL +6,350, 층간 2,800mm. 세대 단면의 +3,200mm를 적용하지 않음. FL과 CH는 별도 확인 값.

## 실제 검증 결과

- E: 원본 작업 폴더에서 `pnpm install --frozen-lockfile`은 `ERR_PNPM_EISDIR` 링크 오류로 실패. 검사 도구가 실행되지 않아 코드 검사 실패와 구분했다.
- 같은 소스를 `C:/Users/woomi/AppData/Local/WoomiModelValidation-20261118`에 복사하고, 실제 환경파일을 제외한 상태에서 고정 lockfile로 설치해 검증.
- 최종 `format:check`, `typecheck`, `lint`, `test`(4개 파일, 20개 테스트), `build` 통과. React Router의 기존 미래 버전 안내 경고가 있으나 빌드 성공.
- Edge 실제 브라우저 검증: 비로그인 redirect, 데모 로그인, 자재 등록/수정, 부위 연결, 9.5mm 저장, 새로고침 유지, 마감층 추가·순서 변경·제거 확인, 바닥/벽/천장 전환, JSON 다운로드/복원, 잘못된 JSON 및 다른 높이 백업 거부.
- 오류 상태 검증: 음수 두께 거부, null 두께 유지, 손상된 로컬 데이터 편집 잠금, 유효 백업으로 복구, 용량 부족 오류 시 입력/기존 설정 보존.
- 데스크톱 1440×1000, 모바일 390×844 / 412×915 / 844×390에서 가로 넘침 없음 확인. 데스크톱 및 모바일 스크린샷 확인. 테스트 브라우저의 등록 데이터는 정리했다.
- 브라우저 1차 검증에서 빈 두께의 null이 0으로 변환되어 정렬 버튼이 잠기던 문제를 발견해 수정하고 동일 흐름을 재검증했다.
- 콘솔 오류·페이지 예외·실패 HTTP 응답: 주요 사용자 흐름에서 0건.
- 확인하지 않은 항목: 원본 E:에서 앱 실행, 실제 PDF 업로드/자동 인식/3D 생성, 공동 저장, 실제 모바일 기기 터치·키보드. 이번 구현은 브라우저 로컬 모델 설정 단계다.
- 검증 과정에서 production 배포·DB 변경·원격 업로드는 하지 않았다.
