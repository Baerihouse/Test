# 84A 확장형 한 세대 골조 3D 초안

- 사용자 승인: 2026-11-18, 첨부 자료로 확인된 골조부터 만들고 회전·확대 가능한 화면 연결.
- 변경 전: 모델 설정만 있고 3D 형상 없음.
- 변경 후: `/model-viewer`에서 첨부 구조평면의 좌표를 추출한 84A 한 세대 부분 골조, 원본 겹침, 부재 선택, 회전/확대/이동, 낮춰 보기, 평면 시점, 이미지 저장 제공.
- 3D 엔진: Three.js + OrbitControls. 외부 CDN/생성형 이미지 API 없이 설치된 패키지 사용. API 근거: https://threejs.org/docs/pages/OrbitControls, https://threejs.org/docs/pages/WebGLRenderer, https://threejs.org/docs/pages/Raycaster
- 경계: route 인증 → feature viewer(브라우저 전용 동적 import) → entity source-based geometry. WebGL 초기화 실패는 오류와 재시도 제공. renderer/controls/geometry/material/texture/RAF/ResizeObserver 모두 정리.
- 원본: 사용자 첨부 `단위세대 구조평면도.pdf`, `벽체일람표-1.pdf`, `슬라브일람표.pdf`, 기존 `201동 단면도.pdf`. 원본은 읽기 전용, 생성한 도면 미리보기만 `apps/web/private/model-references`에 저장. 인증된 리소스 route로만 제공.
- 좌표: PDF x0=326.942749, y0=287.279663 pt, scale=7.596130/200 pt/mm. x방향 14,630mm, y방향 9,920mm 치수와 대조. 좌표는 명시 치수로 보정한 수동 선별 추적이며 범용 자동 벽 인식 아님. x→좌우, plan y→깊이, viewer y→높이. 화면의 모델 원점은 2층 SL(GL+3,550mm).
- AW1 두께250, AW2/AW3/AW11~AW16 두께200은 2층 일람 대조. AW16은 수평 본체만 확정 범주, 꺾임/작은 연장부는 별도 확인.
- 높이: 층간2,800mm - 일반 슬래브 상세210mm = **참고 벽높이2,590mm**. 해당 위치 slab/보 접합 확정 전까지 구조 확정값으로 표시하지 않음. 모든 AW도 '평면·두께 대조 / 높이 참고'로 표시.
- 슬래브: 210mm 일반상세 및 단위세대 범위의 참고 형상. 욕실 단차 타입/슬래브 부호/경계 미확정이므로 주황색 참고 표시, 구조 확정 슬래브로 취급하지 않음.
- 미확정: SW/MW/보는 주황색 윤곽과 원본 겹침으로 표시. 높이·구조사양·개구부 상부 보를 추측해 확정하지 않음. 문/창호 제품, 마감층, 철근, 계단/코어, 전체 층 복제는 이번 단계 밖.
- 검증: 치수 축척·AW폭·기준표고·초안상태·부재개수 테스트, 5개 게이트, 실제 브라우저 WebGL 렌더/조작/선택/보기전환/도면/이미지저장·모바일·인증·오류 경로 확인.
- 롤백: viewer route/nav 및 새 entity/feature 제거 가능. 기존 마감재 localStorage 스키마/데이터는 변경하지 않음.

## 검증 결과

- C: 실행 복사본에서 format/typecheck/lint/test/build 실행. 테스트 5개 파일 23건 통과. E: 원본과 실행본의 앱/자산/패키지·lockfile 내용 동일 여부를 SHA-256으로 대조.
- Edge 실제 WebGL 렌더 확인: 줌 전후 캔버스 변화, 회전 버튼·마우스 드래그, 부재 선택(AW2 1,820×200mm) 및 실제 raycast 선택, 1,200mm 낮춰 보기, 위에서 보기, 표시 토글, PNG 다운로드, 마감 설정 이동 후 재진입.
- 원본 이미지 endpoint는 비로그인 302 로그인 이동, 로그인 후 PNG 및 private/no-store 헤더 확인. 원본 비교 이미지 정상 로드.
- 1920×1080, 1600×900, 1366×768, 390×844, 412×915, 844×390 화면 확인. 세로 화면에서 모델이 잘리던 문제는 화면 비율에 맞춰 시야각을 조정해 수정하고 재확인.
- WebGL context를 사용할 수 없는 브라우저 조건을 시험: 오류·재시도 표시 및 원본 이미지 비교 동작 확인.
- 주요 흐름 콘솔 오류·페이지 예외·4xx/5xx 0건. WebGL 실패 시험에서는 의도한 엔진 오류만 발생.
- 도면 겹침 상부 시점과 3D 화면, 경고가 포함된 저장 PNG를 직접 시각 검토.
- 확인하지 않은 사항: 구조 계산·내력 검증, 부재별 확정 시공높이/접합, SW/MW/보 사양, 단차·인양구, 철근·마감·전체 층, 실제 휴대폰 GPU와 터치. PC 브라우저의 모바일 viewport 검수이며 실기기 검수는 아님.
- 빌드 경고: 동적 로드되는 Three.js chunk가 500kB를 초과한다(약596kB, gzip 약151kB). 초기 다른 화면에 엔진을 넣지 않고 3D 화면 진입 때만 로드. 기존 React Router 미래 옵션 경고도 유지. 오류를 숨기기 위해 경고 한도를 변경하지 않음.
- 생성 데이터와 이미지의 기준은 첨부 PDF이며, AI 이미지 생성이나 임의의 유사 건물 모델을 사용하지 않았다.
