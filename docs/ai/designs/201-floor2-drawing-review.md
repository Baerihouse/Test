# 201동 2층 도면 검토 및 첫 모델 입력 기준

> 후속 반영: 추가 건축/구조 자료를 받았고, 사용자가 2층 SL GL +3,550mm를 확정했다. 현재 마감재 등록 구현 범위와 남은 구조 자료는 [모델 설정 설계](model-settings.md) 참조. 아래는 최초 검토 기록이다.

- 검토일: 2026-11-18
- 출처: 사용자가 지정한 바탕화면 PDF 10개, 각 1페이지
- 상태: 자료 검토 및 입력 데이터 준비 완료. 3D 모델과 프로그램 기능 구현은 미완료.
- 목적: 한 개 층의 골조 / 마감 완료 / 시공 순서 보기를 만들기 위한 자료 충족 여부 확인
- 원본은 읽기만 했으며 외부 서비스로 업로드하지 않았다.

## 합의된 제품 범위

현장별 프로젝트에서 PDF를 중심으로 도면과 보조 자료를 등록한다. CAD도 지원 대상으로 두고 스캔·사진은 이후 확장한다. 한 개 층부터 시작하고, 같은 모델에서 골조·마감 완료·날짜 없는 시공 순서를 전환한다. 인식 결과는 사람이 수정하며, 근거가 없는 값은 확인 필요로 남긴다. 이 문서는 서비스 전체 설계나 자동 인식 정확도 검증을 대신하지 않는다.

모두 문자와 선형 정보를 추출할 수 있는 PDF다. 이미지 기반 스캔 PDF만 있는 상황과는 다르다. 다만 선과 문자가 추출된다는 사실이 벽·문·공간을 정확히 자동 분류했다는 뜻은 아니다. 상세 평면에는 선이 많아 치수선·해칭·가구·설비 기호와 벽을 구분하는 절차가 필요하다.

## 적용 타입

사용자가 2026-11-18에 84A 확장형을 선택했다. 첫 대상은 201동 2층·84A 확장형으로 정한다. 첨부 평면 자체가 해당 확장형과 일치하는지는 단위세대 상세 평면과 교차 확인해야 하며, 선택만으로 일치가 검증된 것으로 처리하지 않는다.

## 확정 가능한 초기 값

| 항목 | 값 | 근거 및 적용 범위 |
|---|---|---|
| 대상 | 201동 2층 | 평면도 제목 |
| 세대 구성 | 84㎡A형 4세대 | 평면 표기와 배치 |
| 수평 전체 치수선 | 58,520 mm | 평면·단면의 표기. 모든 돌출부를 포함한 외곽 경계 크기로 해석하지 않음 |
| 수평 반복 치수 | 14,630 mm × 4 | 평면 하부 치수선 |
| 평면 수직 치수선 | 12,795 = 9,920 + 2,875 mm | 평면 양측 치수선. 임의의 직사각형 바닥으로 대체하지 않음 |
| 2층 SL | GL +3,550 mm | 단면도 |
| 3층 SL | GL +6,350 mm | 단면도 |
| 2층→3층 SL 차 | 2,800 mm | 6,350 − 3,550. 실내 유효 천장고나 벽 높이와 같다고 간주하지 않음 |

SL은 구조 바닥 기준이며, 창호표의 FL은 마감 바닥 기준이다. 두 기준 사이 높이는 바닥 상세 확인 전에는 임의로 합치지 않는다. 원본 축척 문구보다 명시 치수로 실제 길이를 보정하고 가로·세로 치수선으로 교차 확인해야 한다.

## 창호 검토에서 확인한 차이

- 84A 현관문 표기: FSD 10.5X22, 1,050 × 2,200 mm, 1개소/세대.
- 기본형 거실: PW 33X23, 표기 외형 치수 3,300 × 2,300 mm, FL 기준.
- 확장형 거실: PW 33X20, 표기 외형 치수 3,300 × 2,000 mm, 하단 SL +400 mm / 상단 SL +2,400 mm.
- 따라서 창호표의 숫자·표고를 서로 바꾸거나 동일한 창으로 취급할 수 없다.
- 표기 치수는 우선 일람표의 외형 치수로 저장한다. 골조 개구부 치수 및 설치 여유는 별도 상세 확인이 필요하다.
- 평면에 창호 부호와 상세 실명이 충분히 대응되는지 아직 확정하지 않았다. 위치를 추정 배치하지 않는다.

## 단계별 작업과 완료 조건

1. 자료 준비(이번 작업): 10개 PDF 열기·텍스트/선형 정보 확인·전체 페이지 시각 검토, 출처와 확인 필요 항목 기록.
2. 입력 확정: 대상 타입 확인, 상세 평면과 구조·마감 자료 연결. 확보되지 않은 값은 null과 확인 필요 사유 유지.
3. 프로그램 기반: 현장/층/자료 등록, PDF 표시, 명시 치수로 축척 보정, 벽·개구부 인식 결과 확인 및 수정.
4. 3D 형상: 확인된 위치·높이·두께만 생성. 부재별 원본 페이지·확인 상태를 유지하고 치수를 원본과 대조.
5. 보기와 단계: 같은 형상을 공유하는 골조/마감/시공 순서 전환. 재료층별 표시 및 순서 편집.

이번 입력 자료는 1단계를 완료하고 다음 단계의 근거로 사용할 수 있다. 현재 검토만으로 자동 3D 생성 성공, 시공 검토 정확도, 모든 PDF/CAD 지원이 검증된 것은 아니다.

## 검증 기록

- 지정한 10개 파일: 모두 열림, 총 10페이지.
- 10페이지 모두 렌더링하여 시각 검토. 평면·단면의 치수와 84A 창호표의 FL/SL 차이를 텍스트와 비교.
- 파일별 SHA-256과 페이지별 텍스트 길이·선형 개체 수를 JSON에 기록.
- 원본 변경 여부는 검토 후 SHA-256 재계산으로 확인.
- CAD·스캔·사진 인식, 벽 자동 분류, 3D 생성, 브라우저 동작, 앱 빌드는 이번 단계에서 검증하지 않음.
